📖 Инструкция по использованию

  1. Скачайте файл Oktagramma.py (кнопка выше).
  2. Установите Python 3.8+, если ещё не установлен (скачать с python.org).
  3. Запустите программу двойным кликом по файлу или командой python Oktagramma.py.
  4. В консоли выберите 1 (запустить сервер) на одном компьютере, или 2 (запустить клиент) на своём.
  5. При первом запуске автоматически установятся нужные библиотеки (cryptography, pillow).
  6. Для общения в локальной сети: на сервере узнайте IP (ipconfig или ifconfig), в клиенте укажите этот IP и порт 5555.
  7. Для общения через интернет – используйте бесплатные туннели bore.pub или ngrok (инструкция внутри программы).
  8. В чате доступны:
    • /clear – очистить экран
    • /cancel – выйти из приватного режима
    • /users – список пользователей
    • Двойной клик по имени – написать лично
    • Упоминания @ник – привлечь внимание

💡 Подсказка: для выхода из приватного режима нажмите /cancel или закройте окно чата.
